# Basic-CSS — Image Gallery

## Описание проекта

Basic-CSS — небольшой веб-проект с галереей случайных изображений. Страница показывает четыре изображения, загружаемые с сервиса [Picsum Photos](https://picsum.photos).

На странице есть:
- заголовок **Image Gallery**;
- галерея из четырёх изображений;
- ссылка **New images**, при нажатии на которую страница перезагружается и загружаются новые изображения;
- подпись автора приложения.

Оформление страницы выполнено с помощью HTML и CSS: настроены цвета, размеры и расположение элементов, а изображениям добавлены скруглённые углы.

## Как открыть и запустить проект в CodeSandbox

Домашнее задание выполняется в онлайн-редакторе [CodeSandbox](https://codesandbox.io/). Устанавливать программы на компьютер для работы с проектом не требуется.

1. Откройте [CodeSandbox](https://codesandbox.io/) и войдите в аккаунт.
2. Создайте новый Sandbox или выберите импорт проекта из GitHub.
3. Для импорта укажите ссылку на репозиторий:  
   https://github.com/Liachim707/Basic-CSS
4. Дождитесь, пока CodeSandbox загрузит файлы проекта и установит зависимости.
5. Откройте файл `index.html` в редакторе. Изменения HTML и CSS можно вносить прямо в CodeSandbox.
6. Чтобы посмотреть результат, откройте окно Preview (предпросмотр). Если сервер не запустился автоматически, откройте терминал CodeSandbox и выполните:

   ```bash
   npm install
   npm start
   ```

После запуска страница галереи отобразится в предпросмотре. Для загрузки случайных изображений необходимо подключение к интернету.
