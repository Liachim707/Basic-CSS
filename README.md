# Basic-CSS — Image Gallery

## Описание проекта

Basic-CSS — небольшой веб-проект с галереей случайных изображений. Страница показывает четыре изображения, загружаемые с сервиса [Picsum Photos](https://picsum.photos).

На странице есть:
- заголовок **Image Gallery**;
- галерея из четырёх изображений;
- ссылка **New images**, при нажатии на которую страница перезагружается и загружаются новые изображения;
- подпись автора приложения.

Оформление страницы выполнено с помощью HTML и CSS: настроены цвета, размеры и расположение элементов, а изображениям добавлены скруглённые углы.

## Как запустить проект

### Вариант 1. Через npm

1. Установите [Node.js](https://nodejs.org/), если он ещё не установлен.
2. Склонируйте репозиторий или скачайте его архив и откройте папку проекта в терминале.
3. Установите зависимости:

   ```bash
   npm install
   ```

4. Запустите локальный сервер:

   ```bash
   npm start
   ```

5. Откройте в браузере адрес, который появится в терминале (обычно это адрес локального сервера).

### Вариант 2. Открыть без npm

Можно просто открыть файл `index.html` в браузере. Для загрузки изображений потребуется подключение к интернету.
