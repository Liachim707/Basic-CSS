# Basic-CSS

## Описание проекта

Basic-CSS — небольшой веб-проект с галереей случайных изображений. Страница показывает четыре изображения, загружаемые с сервиса [Picsum Photos](https://picsum.photos).

## Что делает проект

- Отображает галерею из четырёх изображений.
- Загружает изображения с сервиса Picsum Photos.
- По нажатию на ссылку New images перезагружает страницу, чтобы получить новый набор изображений.
- Показывает подпись автора: Random image app by Michael.

Оформление страницы выполнено с помощью HTML и CSS: настроены цвета, размеры и расположение элементов, а изображениям добавлены скруглённые углы.

## Как запустить проект

### В CodeSandbox

1. Откройте проект в CodeSandbox.
2. Импортируйте репозиторий GitHub или откройте уже созданный sandbox.
3. Откройте файл index.html и запустите предпросмотр (Preview).

### Локально на компьютере

1. Скачайте или клонируйте репозиторий.
2. Откройте папку проекта в терминале.
3. Установите зависимости:

   ```bash
   npm install
   ```

4. Запустите локальный сервер:

   ```bash
   npm start
   ```

5. Откройте в браузере адрес, указанный в терминале.
